## Запуск проекта

### Установка необходимых модулей

> **Примечание:** Модуль `tkinter` обычно уже входит в состав Python, поэтому устанавливать его отдельно не требуется.

Установите остальные зависимости командой:

```bash
pip3 install flask openpyxl reportlab
```
### Запуск приложения
Перейдите в папку проекта в терминале.

Заполните базу данных начальными данными (если она пустая):

```bash
python seed_data.py
```
Запустите главное приложение:

```bash
python app.py
```
