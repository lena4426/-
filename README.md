# Запуск
Необходимые модули(не считая Tkinter)
pip3 install flask openpyxl reportlab
Из терминала перейти в папку проекта
Заполните базу данных начальными данными (если она пустая):
python3 seed_data.py
Запустите главное приложение 
python3 app.py
